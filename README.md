# San Angeles Observation

A web port of the 2005 4k intro "San Angeles Observation" (C, OpenGL, software synth).
The whole port is one file, `index.html`. Open it in a browser and turn the sound on.

Keys while playing: `Enter` fullscreen, `Esc` stop, `X` debug mode with manual camera.

Original unedited source files from 2004-2005 are in org-src/.
